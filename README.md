# Восхождения на тумбу · упражнение № 29

Мобильное PWA-приложение для Android и iPhone. Обрабатывает видео локально через MediaPipe Pose Landmarker, фиксирует цикл восхождения на тумбу и рассчитывает баллы по возрастной таблице, предоставленной пользователем. **Прототип, не сертифицированная судейская система.**

## Быстрый запуск

1. Распаковать весь ZIP (не один `index.html`).
2. Разместить содержимое папки на HTTPS-хостинге со статическим сайтом, например Netlify Drop или GitHub Pages. Загружать **распакованную папку**, в которой находится `index.html`.
3. Открыть HTTPS-ссылку в Safari на iPhone или Chrome на Android.
4. Нажать «Включить камеру» и разрешить доступ.
5. Разместить телефон на устойчивой опоре сбоку под углом, чтобы были видны обе стопы, колени, таз, плечи, платформа и пол. По возможности обеспечить освещённость и контрастную обувь.
6. Подтвердить, что **реальная платформа имеет высоту 30 см и устойчива**.
7. Нажать «Отметить пол», коснуться видео в месте, где стоят стопы. Затем «Верх тумбы», коснуться верхней поверхности платформы. Повторить после перемещения камеры.
8. Выбрать категорию: «До 35 лет» либо «35 лет и старше» (35 лет относится ко второй группе).
9. Начать стоя перед тумбой и нажать «МАРШ». В течение 10 минут выполнять восхождения. Когда счётчик увидит правильную последовательность, он увеличит число повторений и пересчитает баллы.
10. По окончании скачать протокол событий CSV.

Запуск на компьютере для теста:

```bash
cd stepup-counter-mobile
python -m http.server 8000
```

Открыть http://localhost:8000. Прямой запуск HTML как файла может не работать из-за ES-модулей и доступа к камере. Для доступа к камере через телефон требуется HTTPS. Android: браузер Chrome → установить/добавить на главный экран. iPhone: Safari → Поделиться → На экран Домой.

## Логика подсчёта

1. Обе стопы на полу, ноги и туловище прямые.
2. Одна стопа на верхнем уровне тумбы, другая на полу.
3. Обе стопы на тумбе, колени выпрямлены, туловище близко к вертикали, фиксация в течение **0,34 с**.
4. Одна стопа на полу, другая на тумбе.
5. Обе стопы снова на полу, ноги и туловище прямые, фиксация **0,16 с**. **В этот момент** +1.

При наблюдаемом нарушении этапов, отсутствии выпрямления/фиксации наверху или потере видимости стоп более 1,1 с в середине повторения приложение пишет «НЕ СЧИТАТЬ» и не увеличивает счётчик. При возврате в исходное положение начинается следующая попытка.

Технические параметры (задержки и углы 153° для обеих коленей, допустимый наклон туловища 26°) **не являются числовыми нормативами упражнения**: это консервативные эвристики компьютерного зрения. 2D-видео не позволяет подтвердить реальное касание/опору стоп, физическую высоту 30 см, точность техники при перекрытиях; поэтому возможны ложные зачёты и ложные отказы. Для официального зачёта необходим контролирующий специалист.

## Баллы

Источник – изображение таблицы упражнения № 29, предоставленное пользователем. 99 порогов, от 2 до 100. Для каждого возраста результат – **самый высокий балл, чей порог по повторениям достигнут**; интерполяции нет. Пример: в группе до 35 лет 400 раз = 100; 350 = 75; 298 = 50; 248 = 25; 217 = 2. В группе 35+: 360 = 100; 308 = 75; 258 = 50; 222 = 25; 199 = 2. Ниже 217/199 официальный балл на изображении не указан – приложение показывает «–», а не выдуманное значение 0 или 1.

## Архитектура и проверки

- `index.html` – адаптивный интерфейс.
- `app.mjs` – MediaPipe, камера, калибровка, таймер, уведомления, экспорт CSV.
- `engine.mjs` – конечный автомат подсчёта и извлечение координат.
- `norms.mjs` – таблица нормативов и поиск баллов.
- `reference/table-source.png` – исходная таблица для визуальной сверки.
- `tests/engine.test.mjs` – тесты на принятые/отклонённые повторы, отсутствие фиксации, потерю видимости, все строки таблицы.

Запуск локальных тестов (Node.js 20+): `node --test tests/engine.test.mjs`.

Используется `@mediapipe/tasks-vision@1.1.1` и модель `pose_landmarker_lite` с внешних адресов. Интернет необходим для их первичной загрузки; офлайн-работа не гарантируется. Видеокадры не пересылаются приложением на собственный сервер, но обращения к ресурсам сторонних CDN и связанные с ними метаданные сети возможны. Результаты хранятся локально в браузере и могут быть выгружены вручную в CSV.

**Точность работы на реальных устройствах не измерена.** Тесты покрывают логику, но не фактический видеопоток и не производительность телефона.
